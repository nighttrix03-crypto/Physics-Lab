# Physics Lab | مختبر الفيزياء

مختبر فيزياء تفاعلي باللغة العربية، موافق للمنهاج الجزائري.

يساعد الطالب على استكشاف الظواهر الفيزيائية وفهمها من خلال المحاكاة والدروس والأسئلة.

🔗 الموقع (بعد تفعيل GitHub Pages): https://nighttrix03-crypto.github.io/Physics-Lab/

## محتوى هذه النسخة

| القسم | الموجود الآن | الهدف |
|---|---:|---:|
| المحاكاة التفاعلية | 4 | 72 |
| الدروس | 4 | 72 |
| أسئلة الاختبارات | 8 | 288 |

المحاكيات العاملة الآن: البندول البسيط، حركة قذيفة، السقوط الحر، قانون أوم.
تُضاف بقية المحاكيات والدروس والأسئلة تدريجيًا حتى بلوغ الهدف الكامل.

يشمل الموقع بحثًا وتصفية حسب الوحدة، وأيقونات SVG (دون إيموجي)،
وتحجيمًا تلقائيًا لمسار القذيفة حتى يبقى داخل الشاشة عند كل السرعات والزوايا.

## تشغيل الموقع

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

الموقع ملف واحد مستقل (`index.html`)، دون أي موارد خارجية.

## ملفات المشروع

- `index.html` — الموقع كاملًا: المحاكاة والدروس والاختبار.
- `README.md` — هذا الملف.

## ملاحظة حول قائمة Contributors

قائمة المساهمين (Contributors) في GitHub تُبنى تلقائيًا من أصحاب الـ commits،
ولا يوجد أي ملف أو إعداد داخل المستودع يخفيها ما دام المستودع عامًا (Public).
إخفاؤها ممكن فقط بجعل المستودع خاصًا (Private) من:
`Settings → Danger Zone → Change repository visibility`
لكن ذلك يُخفي المشروع والموقع أيضًا عن الجمهور وعن بحث Google.
